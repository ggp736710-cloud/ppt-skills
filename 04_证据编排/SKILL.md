# 证据编排

每个判断先选定一种证据，再决定画图、写一句经历，还是不展示。图表和故事是证据的两种外形，不分开各写一套无关素材。

## 先读什么

读取汇报任务卡的已核实事实、不讲清单，以及叙事骨架或单页措辞里的「这页只证明」。用户只丢来一组数据时，先问这组数据要证明的那一句判断。

## 怎么选证据

按这个顺序选，命中就停：

1. **已有可核对的数量，且要看趋势、构成、差距或排序** → 数字，配一张图
2. **要在两条路线、两个周期或「做与不做」之间取舍** → 对照
3. **要证明做过、交付过、踩过坑** → 经历。没有可公开经历时不编案例
4. **听众不熟悉这个概念，且判断不依赖精确数字** → 类比
5. **投标要回应评分点或验收条款** → 标准符合，列出条款和对应交付物
6. **以上都没有** → 这页不配证据，退回单页措辞改标题

数量少于 3 个点、或只有一个总数时，不画图，改用一个大数字加一句口径。

## 图表只在这些关系里使用

| 要看出的关系 | 图形 | 停止使用的情况 |
|--------------|------|----------------|
| 随时间升降 | 折线 | 只有两个时间点，改用前后对照 |
| 类别谁大谁小 | 竖柱 | 类别超过 8 个，改成只留前 5 加「其余」 |
| 名次 | 横条 | 没有顺序含义时不用 |
| 占整体的份额 | 环形 | 分类超过 5 个时不用 |
| 阶段流失 | 漏斗 | 各阶段口径不一致时不用 |
| 距离目标还差多少 | 一条进度 | 没有目标值时不用 |

不用立体图，不用双轴，不把一张表伪装成图。能被一句话加一个数字说清的，不画。

## 处理规则

1. **核实等级只有三档。** 「已核实」必须有任务卡中的出处或用户给出的原句；「待核实」是用户说过但没有范围或出处；「示意」是为了说明结构，页面上必须出现「示意」二字。没有第四档。
2. **不新增事实。** 不补充行业平均、竞品份额、名言或新闻案例，除非用户在本轮给出来源。
3. **经历写成四拍。** 对象、当时的约束、做了什么、结果。四拍缺结果就降为待核实，不放进页面正文。
4. **类比只服务一个判断。** 写明「类比的哪一部分对应结论」。对应不上就删掉类比。
5. **投标经历。** 客户名在「不讲」清单里时，用行业和规模代替名字。不写尚未允许公开的合同金额。
6. **述职数字。** 写清周期、口径和个人负责的范围。团队总结果和个人贡献并列时，两行都要有，不能只留更好看的一行。
7. **方案对照。** 推荐路线和放弃路线使用同一组维度：周期、成本、可逆性、验收。缺某一维就写「未评估」，不留空白让人默认它更好。

## 输出格式

每一条判断单独一节。

```

- 选用：数字 / 对照 / 经历 / 类比 / 标准符合 / 不配证据
- 核实等级：
- 为什么是这种：

### 若是数字
- 图形：
- 横轴：
- 纵轴：
- 标出的点：具体到哪一个类别或时间，标什么文字
- 图标题：判断句
- 图下口径：范围、时间、出处
- 不画图时的替代：一个数字 + 一句口径

### 若是对照
- 维度：
- 左侧：
- 右侧：
- 希望眼睛先看到的差异：

### 若是经历或类比
- 页面短句（40字以内）：
- 口述补充（80字以内）：
- 对应到判断的那一点：

### 若是标准符合
- 条款或评分点：
- 交付物：
- 证明材料在附录的位置：
```

## 输出要求

- 每一节都要出现核实等级。示意材料不能和已核实数字放在同一张图里。
- 颜色只指定角色：已达成、未达成、我方、对照方、待核实。具体色值交给视觉规格。
- 标注写到可执行，例如「在 4 月的柱上标出 +12 次，并注明口径是夜班漏检」。
- 没有把握的经历直接删掉，改输出「这条判断目前没有可公开证据」。
- 同一页不要同时放一张图和一段故事。选一个主证据，另一个放进口述补充。
