# 视觉规格

给出一套这次汇报可以逐页套用的规格。规格服务任务卡里的决定：颜色用来区分「已完成、有风险、等待批准」，不是用来装饰。

## 先读什么

读取场景、页数、品牌色约束，以及骨架里的页型。没有品牌色时使用下方场景默认色。有品牌色时，主色改用品牌色，其余角色从品牌色的明度和灰度里取，不另起一套主色。

## 三种场景的默认色

每套只使用主色、点缀、纸色、正文、弱化五色。点缀色只给「需要当场注意」的数字或请求，面积保持最小。

**述职｜沉稳纸面**

| 角色 | 色值 | 用在 |
|------|------|------|
| 主色 | #1B3A4B | 标题、封面条 |
| 点缀 | #8C5A3C | 缺口、请求批准的资源 |
| 纸色 | #F4F1EA | 背景 |
| 正文 | #243038 | 要点 |
| 弱化 | #C8BEB0 | 分隔线、出处 |

**项目方案｜评审桌面**

| 角色 | 色值 | 用在 |
|------|------|------|
| 主色 | #1F4D3A | 标题、推荐路线 |
| 点缀 | #C47B2B | 预算、不可逆决定 |
| 纸色 | #F7F6F3 | 背景 |
| 正文 | #1E2422 | 要点 |
| 弱化 | #D5D1C8 | 放弃路线的底色 |

**投标｜客户现场**

| 角色 | 色值 | 用在 |
|------|------|------|
| 主色 | #16324F | 标题、客户目标 |
| 点缀 | #1F7A8C | 评分点编号 |
| 纸色 | #F3F6F8 | 背景 |
| 正文 | #1C2833 | 要点 |
| 弱化 | #8A94A0 | 对照列，不用于我方承诺 |

用户要第二套时，只替换主色和点缀，纸色、正文、弱化保持不变，避免两套方案变成两套字体体系。

## 字号

投影优先。页数多也不缩小正文来塞内容。

| 元素 | 字号 | 字重 |
|------|------|------|
| 封面标题 | 36–44pt | 粗 |
| 页标题 | 28–32pt | 粗 |
| 要点 | 18–20pt | 常规 |
| 图表轴与出处 | 12pt | 常规，用弱化色 |
| 单独放大的数字 | 54–64pt | 粗 |

字体优先使用用户模板里已有的黑体或思源黑体。不在规格里同时推荐两种正文字体。

## 六种版式

一页只选一种。同一页型在全稿里用同一种版式。

| 版式 | 结构 | 适合 |
|------|------|------|
| 决定条 | 顶部一条请求，下面三块等宽证据 | 总览、请求 |
| 左判断右证据 | 左 40% 标题和要点，右 60% 图或对照 | 结果、原因 |
| 双栏取舍 | 中间一条分隔，左右同一组维度 | 路线对照、做与不做 |
| 单指标 | 一个数字居中，下方一行口径 | 只有一个已核实数字的页 |
| 阶段轨 | 横向 3–5 段，每段只有阶段名、负责人和完成标志 | 计划、实施 |
| 边界页 | 上半是风险和触发条件，下半是本次不包含的范围 | 风险、投标边界 |

页边距保持画面短边的 8%。标题左对齐。封面可以居中，内容页不要混用居中和左对齐。

## 处理规则

1. 主色、点缀、弱化之外不再加新颜色。图表系列超过两种时，第二种用主色的 40% 明度，不引入新色相。
2. 待核实的数字用弱化色，已核实的缺口或请求用点缀色。不要用红绿对作为唯一区分。
3. 投标的评分点编号用点缀色，正文仍用正文色，避免整页都是强调色。
4. 公司模板已规定色值和字体时，输出「沿用模板」列，只补充版式选择和自检，不覆盖模板。

## 输出格式

```
# 视觉规格

- 场景：
- 品牌色：有则写色值；无则写「用场景默认色」
- 页数：

## 用色
（五色表）

## 逐页版式
| 页 | 页型 | 版式 | 点缀只用在 |
|----|------|------|------------|

## 第二套（仅在用户要求备选时）
只列替换后的主色和点缀。

## 做完自检
- [ ] 标题都左对齐，封面除外
- [ ] 点缀色只出现在请求、缺口或评分点
- [ ] 同一页型的版式相同
- [ ] 正文不小于 18pt
- [ ] 待核实信息没有用点缀色
```

## 输出要求

- 色值写成六位十六进制。
- 逐页版式必须覆盖骨架里的每一页；没有骨架时，按场景默认页序给版式，并注明「页序未定」。
- 不改写页面文案。发现某一页文字装不进所选版式时，写「退回单页措辞删到 3 条」，不在这里缩小字号。
