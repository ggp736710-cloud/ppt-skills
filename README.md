# 7 个让 AI 逐步做好 PPT 的 Skills

一组面向述职、项目方案和投标汇报的中文 AI 工作流技能。它们覆盖从澄清汇报目标到成稿复查的完整过程，强调事实可追溯、决策明确、页面与口述相互配合。

## 技能列表

| 顺序 | 技能 | 作用 |
| --- | --- | --- |
| 01 | [汇报任务卡](./01_汇报任务卡/SKILL.md) `briefing-card` | 澄清场景、听众、决策、已核实事实和约束 |
| 02 | [叙事骨架](./02_叙事骨架/SKILL.md) `narrative-spine` | 将任务卡展开为有逻辑的页面顺序 |
| 03 | [单页措辞](./03_单页措辞/SKILL.md) `slide-wording` | 编写每页判断句、要点和演讲者备注 |
| 04 | [证据编排](./04_证据编排/SKILL.md) `evidence-design` | 为页面判断选择证据与图表表达 |
| 05 | [视觉规格](./05_视觉规格/SKILL.md) `visual-spec` | 形成可复用的配色、字号和版式规范 |
| 06 | [口述节奏](./06_口述节奏/SKILL.md) `spoken-track` | 编写逐页口播、时长和过渡句 |
| 07 | [成稿复查](./07_成稿复查/SKILL.md) `deck-review` | 检查事实、逻辑、页面负载和汇报时长 |

## 推荐使用顺序

`汇报任务卡 → 叙事骨架 → 单页措辞 + 证据编排 + 视觉规格 → 口述节奏 → 成稿复查`

先完成任务卡，再按顺序推进。证据、文案和视觉规格可以围绕同一份骨架协同完善；完成后用口述节奏和成稿复查收尾。

## 安装

将需要的技能目录复制到所用 AI 助手支持的 skills 目录中，并保留目录名及其中的 `SKILL.md`。也可以按工具要求调整放置路径。技能以 Markdown 指令文件提供，不包含特定平台的运行时代码。
